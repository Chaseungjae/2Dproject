# 2D 액션 플랫포머

점프 버튼을 **누르고 있는 시간만큼 높이와 거리가 결정되는** 홀드 점프와, 벽에 부딪혀 튕겨 나오는 **반사 물리**가 핵심인 야간 테마 2D 플랫포머입니다. 혼자 기획부터 구현까지 진행했습니다.

## 구현한 것

- **차지 점프** — 누른 시간에 비례해 점프력이 `JUMP_FORCE → MAX_JUMP_FORCE`로 선형 보간
- **벽 반사** — 충돌 노멀로 `bounce()` 벡터를 계산하고 점프 파워에 따라 감쇠
- **위험 타일 넉백** — 접촉 시 카메라 쉐이크 + 넉백, 확률이 누적되는 강한 반응 변수
- **상태별 카메라 오프셋** — 상승/낙하 시 카메라 위치 보간
- **클리어 타임 기록** — 싱글톤(`GameState`)으로 경과 시간 계산 후 씬 전환
- 배경 셰이더 10종, 효과음·BGM, 엔딩 연출

```gdscript
# 점프 버튼을 누른 시간에 비례해 점프력 증가
applied_jump_force = JUMP_FORCE + (MAX_JUMP_FORCE - JUMP_FORCE) * (jump_hold_time / MAX_HOLD_TIME)
```
